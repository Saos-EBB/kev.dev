YourBrand – Multitenant-Showcase
================================
Eine Codebasis, vier Mandanten. Gleicher Ablauf, Unterschiede kommen nur aus der
Mandanten-Config (tenants/<slug>/tenant.json).

vergleich.mp4                 alle vier Abläufe 2x2 nebeneinander
vergleich-NN-<schritt>.png    pro Schritt alle Mandanten im Raster
<mandant>/NN-<schritt>.png    Einzel-Screenshots
<mandant>/ablauf.mp4|.webm    Einzelvideo

Mandanten
  kiez          KiezConnect   core                       hell, Orange   de/en/Leichte Sprache
  campus-match  Campus Match  premium ohne Hidden Zone   dunkel, Pink   de/en
  miteinander   Miteinander   connect ohne Bezahlung     hell, Blau     Leichte Sprache (Standard)
  underground   Underground   premium + Hidden Zone      dunkel, Cyan   de/en/leet

Hinweise
  - Aufgenommen in einer Testumgebung (lokales Postgres/Redis, S3-Ersatz), nicht im Docker-Stack.
  - "Offene Anfragen / Aktive Chats: —" im Dashboard ist ein bekannter, bestehender Fehler
    (Endpunkt verlangt Admin-Rolle), unabhängig vom Multitenant-Umbau.
  - Neu erzeugen: scripts/tenant.sh up all && cd showcase && npm run showcase
